# 🔬 Researcher Agent — Multi-Agent AI System

An autonomous, collaborative **4-Agent Research Assistant** built with LangChain v1.x, Groq LLMs, and Tavily. The system orchestrates four specialized AI agents using a shared state pipeline to search the live web, extract deep webpage content, synthesize comprehensive markdown reports, and critique/grade the output through an interactive Streamlit UI.

---

## 📌 Architecture Flow

The pipeline executes sequentially, passing artifacts across stages via an in-memory **Shared State**:

```
[ User Query / Topic ]
          │
          ▼
┌───────────────────┐
│   Search Agent    │ ───► Tavily Search API (Top 5 Sources & URLs)
└─────────┬─────────┘
          │ (search_result)
          ▼
┌───────────────────┐
│   Reader Agent    │ ───► Deep Scraper (Trafilatura & BeautifulSoup Fallback)
└─────────┬─────────┘
          │ (scraped_content)
          ▼
┌───────────────────┐
│   Writer Agent    │ ───► LCEL Synthesis (Comprehensive Markdown Report)
└─────────┬─────────┘
          │ (report)
          ▼
┌───────────────────┐
│   Critic Agent    │ ───► LCEL Evaluator (Quality Assessment & 1-10 Scoring)
└─────────┬─────────┘
          │ (feedback)
          ▼
[ Streamlit UI: Interactive Outputs + .md Download ]
```

### Shared State Lifecycle
The pipeline maintains a synchronized state dictionary across execution steps:
- **`topic`**: Research subject specified by user.
- **`search_result`**: Live internet URLs, titles, and snippets fetched by the **Search Agent**.
- **`scraped_content`**: Clean extracted textual content scraped by the **Reader Agent**.
- **`report`**: Structured, citation-backed draft generated by the **Writer Agent**.
- **`feedback`**: Critique, score, and verification notes generated by the **Critic Agent**.

## 🛠️ Tech Stack

- **Runtime & Environment:** Python 3.12+
- **Package & Dependency Manager:** [uv](https://github.com/astral-sh/uv) (Fast Python packaging)
- **Agent Orchestration:** LangChain v1.x (`create_agent` & LCEL Chains)
- **LLM Provider:** [Groq](https://groq.com/) (`ChatGroq` / High-throughput LLM inference)
- **Web Search Engine:** [Tavily Search API](https://tavily.com/)
- **Web Scraping & Extraction:** Trafilatura & BeautifulSoup4
- **User Interface:** Streamlit (Dynamic step tracker, collapsible agent inspect panels, and report download)

## 🚀 Setup & Installation

### 1. Clone the repository & sync dependencies
Using `uv`, setup the virtual environment and install all locked dependencies:

```bash
uv sync
```

### 2. Configure Environment Variables
Create a `.env` file in the project root with your API keys:

```bash
GROQ_API_KEY="your_groq_api_key_here"
TAVILY_API_KEY="your_tavily_api_key_here"
```

### 3. Run the Streamlit Application
Launch the interactive web application:

```bash
uv run streamlit run app.py
```

*(Optional)* You can also run the terminal pipeline directly via:
```bash
uv run python main.py
```
